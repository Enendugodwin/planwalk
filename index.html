Planwalk didn’t start

Planwalk is a Vite app, so it must be opened through a local server — not by double-clicking index.html. Browsers block the app's JavaScript when it is opened from the file system.

From the planwalk folder, run:

npm install npm start

Then open http://localhost:5180. On Windows you can also double-click start-planwalk.cmd.

If the server is already running, check the browser console for the error that prevented startup.
